Sunrise Worlds Cheats Checker 0.1.1 (Windows x64)

1. Распакуй архив целиком: папка signatures/ должна лежать рядом с swcc.exe.
2. Запусти swcc.exe. Сначала появится соглашение - прочитай и прими, без
   этого ничего не читается. При следующем запуске окно спросит заново.
3. Впиши свой ник в игре - без него проверка не начнётся, ник попадает в
   отчёт.
4. Отметь, что проверять: найденные папки игры, любую свою папку или целый
   диск. Папка с признаками Minecraft читается полностью, всё остальное
   обходится по именам, размерам и датам изменения.
5. При желании поменяй настройки проверки (чтение содержимого, распаковка
   архивов, логи, минимальная уверенность) - профиль записывается в отчёт.
6. Нажми «Начать проверку», дождись заключения и нажми «Скачать отчёт .swcc».
7. Перешли сохранённый файл администратору сам.

Интернет не используется: в программе нет адреса сервера, она физически не
умеет ничего отправлять. Отчёт появляется на диске только после того, как ты
сам его сохранил. Браузер, пароли, переписка, буфер обмена, документы, фото,
скриншоты, клавиатура и список процессов не читаются.

Windows может предупредить о неизвестном издателе - сборка не подписана.

Консольный режим:

  swcc scan --player <ник> <папка> [...] --i-accept
  swcc verify <файл.swcc>
  swcc help

Флаги scan: --out файл.swcc, --no-deep (не распаковывать архивы),
--no-content (только имена и размеры), --no-logs (не читать логи и строки
запуска), --full (обойти диски целиком). Без --i-accept скан не запускается.
