# Sunrise Worlds Cheats Checker (swcc)

Автономная проверка твоего компьютера на признаки чит-клиента Minecraft.
Один .exe без установки, без сети и без админских прав.

## Как пользоваться

1. Запусти `swcc.exe` — сначала появляется соглашение: что именно читается и
   что программа не делает. Без принятых кнопок ничего не читается, при
   следующем запуске окно спросит заново.
2. Впиши свой ник в игре — без него проверка не начнётся. Ник записывается в
   отчёт, чтобы админ понимал, чья это проверка.
3. Отметь, что проверять: найденные папки игры, любую свою папку или целый
   диск. Папку с признаками Minecraft программа читает полностью, всё
   остальное обходит по именам, размерам и датам изменения.
4. При желании поменяй настройки проверки: чтение содержимого, распаковка
   архивов, логи и строки запуска, минимальная уверенность признака. Выбранный
   профиль тоже попадает в отчёт — выключенное означает «не досмотрено», а не
   «чисто».
5. Нажми «Начать проверку», дождись заключения и нажми «Скачать отчёт .swcc».
   Перешли файл администратору сам. Никуда ничего не уходит: файл появляется
   только после того, как ты его сохранил.

`signatures/` должна лежать рядом с `swcc.exe` — это база признаков, её можно
обновлять без пересборки (а своим списком — `signatures/custom.toml`).

## Консольный режим

```
swcc scan --player <ник> <папка> [...] --i-accept
          [--out файл.swcc] [--no-deep] [--no-content] [--no-logs] [--full]
swcc verify <файл.swcc>
swcc help
```

Без `--i-accept` соглашение просто печатается в консоль и проверка не
запускается; `--player` обязателен. `--full` добавляет обход дисков по
метаданным, `--no-deep` отключает распаковку архивов, `--no-content` оставляет
только имена и размеры, `--no-logs` — без логов и строк запуска.

## Сборка

```
cargo build --release      # target/release/swcc.exe
cargo test                 # 22 проверки формата, базы, ника и путей
```

Шрифт Inter лежит в `assets/fonts/` и вшивается в exe через `include_bytes!`.
Rust 2024. Зависимости: `eframe`/`egui`, `walkdir`, `zip`, `regex`,
`serde`+`toml`, `sha2`, `base64`, `chrono`, `anyhow`, `hex`, `rfd`;
`winresource` — только build-dependency для встраивания иконки на Windows.
HTTP-клиентов и других сетевых crate в дереве зависимостей нет.

## Что программа не делает

- Не выходит в сеть: адресов сервера в коде нет.
- Не читает браузер, пароли, переписку, буфер обмена, документы, фото,
  скриншоты, клавиатуру и список процессов.
- Не обходит `assets/`, `libraries/`, `runtime/`, `bin/` и папки нативок.
- Не трогает системные каталоги Windows при проверке дисков: там берутся
  только имя, путь, размер и дата файла, а содержимое открывается лишь там,
  где имя уже совпало с базой.
- Токены из строк запуска (`--accessToken`, `--xuid`, `--clientId`) вырезаются
  до записи в отчёт.
- Ничего не удаляет, не исправляет и не блокирует.

Чистый отчёт — не доказательство честной игры: самописный или пересобранный
чит база может не увидеть. Решение по отчёту всегда ручное.
